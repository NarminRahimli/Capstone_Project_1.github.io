# Capstone Project 1

## Overview
This is a multi-page personal website built using **HTML only**.
The website shows my knowledge of HTML, including headings, paragraphs, lists, tables, forms, links, and images.

---

## Pages
The website has **4 main pages**:

1. **Home**  
   - Introduction about myself  
   - Profile picture  
   - Use of headings, paragraphs, lists, and emojis  

2. **Education**  
   - Table showing my education history  

3. **Weekly Schedule**  
   - Full weekly timetable in a table format  

4. **Contact Me**  
   - Form with text inputs, textarea, and submit button
