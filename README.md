# Capstone Project 2 - Narmin Rahimli

This project is my **Capstone Project 1 & 2** for my Web Development course.  
It is a multi-page personal website built using HTML and CSS.  

---

##  Project Structure
The website consists of the following pages:
- 🏠 **Home** – Introduction about me, my hobbies, and skills.  
- 🎓 **Education** – Table showing my academic background and courses.  
- 📅 **Weekly Schedule** – My weekly timetable designed with HTML tables.  
- ✉️ **Contact Me** – A form that allows visitors to send a message.  
- 🖼️ **Gallery** – A responsive photo gallery of my hobbies and interests.

---

##  Features and Technologies
- **HTML5** structure and semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3** for layout, styling, and hover effects.
- **Google Fonts** integration for typography.
- **Sticky navigation bar** with hover and active link effects.
- **Responsive layout** using Flexbox, Grid, Float layout.
- **Favicon**, emojis, and consistent design across all pages.
- **Form styling** with input types, radio buttons, and dropdowns.

---

## What I Learned
Through this project, I learned how to:
- Structure a multi-page website using HTML.
- Style elements consistently using an external CSS file.
- Apply layout techniques like Flexbox and Grid.
- Make responsive web pages that adapt to different screen sizes.
- Deploy websites using **GitHub Pages**.
